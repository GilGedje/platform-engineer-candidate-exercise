# Deployment exercise

Bring Notes Lab to life on local Kubernetes, with PostgreSQL, Prometheus, and Grafana.

**Role:** mid-level DevOps / platform engineer  
**Time:** up to two working days, capped at 16 active hours  
**Follow-up:** a 60-minute discussion and practical walkthrough

## Start here

Read the scenario first, then work through one part at a time. Each page explains a single stage and what you need to demonstrate.

| Part | What you will do |
|---|---|
| [00 · The scenario](00-scenario.md) | Understand the handover, supplied materials, and local environment. |
| [01 · Repair the image](01-repair-the-image.md) | Investigate runtime failures and build a corrected container image. |
| [02 · Deploy with Helm](02-deploy-with-helm.md) | Author a chart and connect the application to persistent PostgreSQL. |
| [03 · Add monitoring](03-add-monitoring.md) | Collect application metrics and build a useful Grafana dashboard. |
| [04 · Verify recovery](04-verify-recovery.md) | Prove data persistence, outage recovery, and a Helm upgrade. |
| [05 · Submit and review](05-submit-and-review.md) | Prepare your handoff and understand the assessment criteria. |

Keep the [application reference](06-application-reference.md) open when you need environment variables, endpoints, metric names, or documentation links. It is a reference page, not an additional assignment.

Documentation and ordinary web search are allowed. **AI assistance is excluded**; see the [tools policy](05-submit-and-review.md#tools-and-assistance-policy). Record what you learn and submit partial work if you reach the time cap.
